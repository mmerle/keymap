# Planck Rev 6 Drop

Four-layer Planck layout for development work.

## Layers

- Base: QWERTY with Control/Escape, Symbol and Number layer keys.
- Symbol: programming punctuation and symbols.
- Number: number row, number pad, arrows and navigation.
- Function: function keys, media, brightness, RGB and bootloader controls.

Holding Symbol and Number together activates the Function layer. Pressing both Shift keys activates Caps Word.

## Build

```sh
make planck
```

## Flash

```sh
make flash-planck
```
